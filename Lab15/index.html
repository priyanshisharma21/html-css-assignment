Lab 15: Responsive Pages with Media Queries

Aim: Use a media query to change a layout, make a picture scale with its box, and set text sizes with rem units.

  1. mobile-first.html: Cards stack on phones and sit side by side from 600px
  2. responsive-image.html: Image with max-width 100% and height auto
  3. responsive-text.html: rem font sizes and a 600px media query for the h1
