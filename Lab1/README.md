## Tasks

| # | What to do | Commands |

| 1 | Create `html-lab`, start a repository, set name and email for this repo only | `git init`, `git config --local user.name "..."`, `git config --local user.email "..."`, `git config user.name`, `git config user.email` |

| 3 | Add an h2, commit, view history | `git commit -m "Add next meeting heading"`, `git log --oneline` |

`index.html` in this folder is the file from the end of Task 3 (h1 and h2).
